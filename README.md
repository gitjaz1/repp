# Syed Jazib Hassan — Interactive Portfolio CV

Responsive static portfolio with a scroll-driven day-to-night visual, an illustrative rooftop interaction, project screenshots, and a downloadable résumé. The page is broader than solar: computer vision, RAG, local LLM workflows, and automation are all represented.

## Deploy to Vercel
1. Upload this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Choose **Other**, leave the build command empty, and set output directory to `.`.
4. Deploy.

## Files
- `index.html` — website and interactions
- `images/` — Solar Lead Engine and Solar Park Ballast Calculator screenshots
- `Syed_Jazib_Hassan_Resume.pdf` — updated one-page résumé

The clickable rooftop in the hero is an illustrative demo, not an engineering-grade solar calculator. Solar Lead Engine metrics are labeled as sample figures from the provided screenshot. Google Fonts are loaded externally; project screenshots and résumé are local.
